A highly responsive, premium futuristic 3D landing page built for the **Techfest IIT Bombay College Ambassador Program**. Designed without heavy frontend frameworks, this project leverages pure Vanilla JavaScript and ES Modules to deliver an award-winning cinematic scroll experience featuring procedural 3D environments, dual-tone neon lighting, and buttery-smooth camera choreography.

## ✨ Advanced Features

*   **Cinematic WebGL Scene:** A performant Three.js environment featuring a wireframe Torus Knot, a pulsing procedural Energy Core, multi-colored orbital rings, and an organic 3D particle starfield.
*   **Scroll Storytelling:** GSAP ScrollTrigger tightly synchronized with Lenis Smooth Scroll to drive the 3D camera through 6 distinct spatial dimensions as the user scrolls.
*   **Premium Post-Processing:** `EffectComposer` and `UnrealBloomPass` integration for an ethereal, high-end cyberpunk neon glow without blowing out text readability.
*   **Micro-Interactions:** Magnetic CTA buttons, 3D tilt-tracking glassmorphism tech cards, and a custom dual-ring mouse cursor utilizing GSAP `quickTo` for zero-latency tracking.
*   **Production-Ready & Accessible:** Strictly responsive, optimized for mobile GPUs (dynamic particle reduction and bloom scaling), and fully compliant with `prefers-reduced-motion` for accessibility.
